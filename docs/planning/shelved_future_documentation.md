## Purpose

This document lists future systems that may need documentation later.

These systems are intentionally shelved and should not receive full documentation until active development begins.

This keeps current documentation focused on systems that already exist or are actively being built.

---

## Rule

Only move an item from this list into full documentation when:

* The system enters active development
* Code or scenes are created for it
* Design decisions need to be locked in
* Another system depends on it

## Notes

Shelved does not mean abandoned.

It means the system is recognized but intentionally delayed so current development can remain focused.

Future systems listed here are placeholders only.

Inclusion in this document does not guarantee implementation.

Systems may be merged, split, redesigned, renamed, or removed as development progresses and gameplay testing provides feedback.

This document exists to preserve ideas, not to lock development into specific future decisions.
